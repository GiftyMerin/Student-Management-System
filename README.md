# Student Management System

A lightweight Python application designed to manage student records, track information, and streamline administrative tasks.

## 🚀 Features

- Add, update, and remove student records
- View and search student details
- Simple terminal-based interface

## 📋 Prerequisites

- Python 3.x installed on your machine
